# HEMS
Eerste mobiele HEMS-versie voor zonne-energie.

## Starten
Python 3.11+:
pip install -r requirements.txt
python app.py

Open daarna op de iPhone Safari met het lokale adres van de computer, bijvoorbeeld http://192.168.1.20:8000

Deze eerste versie gebruikt demo-data. De echte Elekeeper/SAJ-koppeling komt in de volgende stap.
